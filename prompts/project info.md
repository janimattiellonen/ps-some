# Project info

A web app for generating images to social media platforms like Instagram and Facebook. For example an image containing a picture of a member along with his/her PDGA number and results in a competition, or an image containing information about an upcoming competition.


## Basic requirements
- React 19
- Typescript
- modern web framework
- possibility to upload images
- possibility to download an augmented version of the downloaded image
    - for example merging two images into one and then downloading it
- currently no need for a dedicated API backend
