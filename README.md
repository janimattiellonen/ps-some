# Puskis Some

A web app for generating social media images for disc golf events. Create images containing player profiles with PDGA numbers, competition results, and upcoming event information for platforms like Instagram and Facebook.

## Tech Stack

- React 19
- TypeScript
- Vite
- StyleX

## Requirements

- Node.js 22.12.0 or higher

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at http://localhost:5165
